# Notes

Working notes. Unlike `../decisions/`, everything in here is expected to change.

- **[open-questions.md](open-questions.md)** - every `[unverified]` flag and unresolved
  conflict, ordered by what it blocks. Close these before they drive decisions.
- **[next-steps.md](next-steps.md)** - the worklist, ordered so the cheap thing that could
  invalidate everything else comes first.

When a question closes, move the answer into the relevant ADR in `../decisions/` and strike
it here. The point of the split is that ADRs record what is settled and notes record what is not.
