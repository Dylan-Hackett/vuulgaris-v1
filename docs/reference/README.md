# Reference sources

Original schematics and datasheets the design was worked from, kept so
`netmap.json` can be checked against them rather than against a transcription.
See [`../review-packet.md`](../review-packet.md) for what is verified and what
is not.

Anything here is a source document, not a design output. Nothing in this folder
is generated by the toolchain and nothing reads from it automatically.
